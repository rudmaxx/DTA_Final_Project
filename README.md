# ShopSphere – Data Analytics Final Project

## Project Overview

This project was completed as the final assignment of the Data Analytics course.

The objective was to analyze data from a global online marketplace using SQL and Tableau, identify business insights, and provide recommendations based on the analysis.

---

## Dataset

The project uses five datasets:

- customers
- orders
- order_items
- products
- marketing

The data covers the years 2022–2024.

---

## Tools

- SQL (SQLite)
- Tableau Public
- Microsoft Excel

---

## Project Structure

### 1. SQL Analysis

- Revenue by region and year
- Top 10 customers
- Product category analysis
- High-value customer analysis
- Marketing ROI

### 2. Tableau Visualizations

- Revenue seasonality
- Marketing ROI
- Category performance
- Regional trends
- Customer contribution (Pareto)

### 3. Dashboard

Interactive CEO dashboard with KPIs and filters.

### 4. Business Analysis

Recommendations regarding:

- Marketing budget allocation
- Product categories
- Customer segmentation

### 5. A/B Test Analysis

Statistical analysis of the checkout experiment.

---

## Key Insights

- High-value customers generate the majority of revenue.
- Marketing channels differ significantly in ROI.
- Some categories generate high revenue but lower profitability.
- Customer segmentation provides better business decisions than overall averages.
